# VidGrab v1.0.49

Date: 2026-11-09

## Changes

- Removed all Bangla keywords from the Home category filters. Music, News and Movies now match history using English keywords only.
- Removed clipboard detection entirely: no copied-link suggestion after the Home search bar, no setting toggle, and no clipboard-reading code.
- Removed the comments preview and comments sheet from the video page; comments are no longer fetched when a video opens.
- Redesigned the video action area: a primary Download button, a tools row with thumbnail save, copy title, description and tags directly under it, and a compact row for Watch later, Listen, Share and picture-in-picture.
- Autoplay now starts the next suggested video immediately when the current one ends, with no "Up next in 5" countdown.
- Removed the "Hot searches" and "View sites" sections from the Search screen.
- Rebuilt the in-app browser around a Chrome-style new-tab page: Google search box, shortcuts from recent pages and saved sites, and a single-line URL bar with back, forward, home and refresh. YouTube links now stay in the browser instead of jumping to the native video page.
- Added "Site settings" under Settings → General to add, remove and arrange saved sites.
- Removed the small platform source badges (YT, IG, FB and similar) from video thumbnails.
- Rebuilt the About page: the Home wordmark replaces the app icon, with version pills, app stats, feature highlights, developer details, project links, open-source credits and a legal footer.
- Redesigned the update sheet: brand wordmark header, new-update/size pills, installed → available version comparison, cleaner release notes, verification note and a clearer primary action.
- Moved the wordmark into `core:designsystem` so Home, About and the update sheet all share one drawable.
- Fixed low-quality thumbnails on the Music tab:
  - YouTube thumbnails are requested at `maxresdefault.jpg` instead of the small variant returned by music search.
  - `lh3.googleusercontent.com` album art is requested at 1440px instead of the original 120px size.
  - Thumbnail cards now step down to a smaller CDN size when a high-resolution frame does not exist, so the card never stays blank.
