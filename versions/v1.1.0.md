VidGrab 1.1 is the first stable release with optional account sign-ins. This is a signed release build, not a debug build.

## Highlights

- **Optional account sign-ins** for YouTube, Instagram, Facebook and TikTok. The site's own page handles the login, so passwords never pass through VidGrab; only the resulting session cookies stay on the device.
- **Signed-in YouTube** sessions now power the home feed, search, related videos, playback and downloads, including videos that require an account.
- **Account switching and sign-out** from Settings → Accounts. Signing out removes that site's account cookies from the device.
- **Any other site** can be signed in from the built-in browser; downloads from that site use the same session automatically.
- **Subtitle download and playback**, with a subtitle menu in the player.
- Video actions moved into an overflow menu, keeping the player area focused on the video.

## Fixes

- Fixed account feed session index parsing and nullable account feed handling.
- Bound the YouTube auth hash to the request origin.
- Kept account request headers out of video playback.
- Fixed login screen imports and account feed smart casts.

## Downloads

- `VidGrab-v1.1.0-arm64-v8a.apk` — most phones (recommended, ~35% smaller).
- `VidGrab-v1.1.0-armeabi-v7a.apk` — older 32-bit ARM phones.
- `VidGrab-v1.1.0.apk` — universal APK for manual installs.

Every APK has a matching `.sha256` checksum.

## Upgrade note

Builds up to 1.0.66 used the CI run number as the Android version code and as the tag's last component. From 1.1.0 the tag is semantic and the version code is derived from it. If you are on 1.0.66, install this APK once manually; in-app updates resume from 1.1.0 onward.
