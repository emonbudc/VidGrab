# VidGrab v1.0.51

Date: 2026-11-09

## Changes

- Enabled Firebase Crashlytics and anonymous analytics in official builds. CI restores the Firebase config from the `GOOGLE_SERVICES_JSON` secret before Gradle starts, so crashes and handled errors reach the Firebase console.
- Registered both `com.vidgrab.app` and `com.vidgrab.app.qa` with the Firebase project so release and QA builds resolve the same config.
- Fixed the release-secret setup script to store the keystore under the `KEYSTORE_BASE64` name the workflow expects.
- `download_completed` now carries `bytes` and `duration_sec`, so Firebase shows total downloaded videos, data volume and minutes once those params are registered as custom metrics.
- Crash reporting stays off in debug builds and follows Settings → Privacy.
- Added an admin dashboard for release downloads, app installs and completed video downloads, backed by a nightly Firebase/GA4 snapshot workflow.
